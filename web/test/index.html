¿Navegas a través de XDP?

Comprueba si tu dispositivo está utilizando los servidores DNS de XDP para resolver dominios.

Limitaciones conocidas:
• Si tu navegador usa su propio DNS seguro (DoH) o activaste iCloud Private Relay, el test puede dar negativo aunque tengas XDP configurado.
• VPNs con DNS propio también producen falso negativo.
• El resultado refleja únicamente este dispositivo y esta red.
🔒 Privacidad: el test genera un token aleatorio único que solo existe durante segundos en memoria del servidor. No se guardan IPs de navegación ni historiales.
