Guía de Configuración

  1. Ve a Ajustes → Redes e Internet / Conexiones → Más ajustes de conexión.
  2. Pulsa sobre DNS privado (Private DNS).
  3. Selecciona "Nombre de host del proveedor de DNS privado".
  4. Escribe: dns.xdp.es y pulsa Guardar.
  1. Descarga el perfil .mobileconfig (DoH) desde el navegador Safari.
  2. Abre Ajustes y pulsa en "Perfil descargado" en la parte superior.
  3. Pulsa Instalar en la esquina superior derecha y confirma con tu código de desbloqueo.
  1. Abre Configuración → Red e Internet → Wi-Fi o Ethernet.
  2. En "Asignación de DNS", pulsa Editar y selecciona Manual.
  3. Activa IPv4 e introduce como DNS preferido: 85.208.114.51.
  4. En "Cifrado DNS", selecciona Solo cifrado (DNS a través de HTTPS) y como plantilla: https://dns.xdp.es/dns-query.

Para systemd-resolved, edita el archivo /etc/systemd/resolved.conf:

[Resolve]
DNS=85.208.114.51#dns.xdp.es 2a0e:97c0:c40::51#dns.xdp.es
DNSOverTLS=yes
DNSSEC=allow-downgrade

A continuación, reinicia el servicio con: systemctl restart systemd-resolved

Chrome / Brave / Edge: Configuración → Privacidad y Seguridad → Usar DNS seguro → Con: Personalizado → https://dns.xdp.es/dns-query
