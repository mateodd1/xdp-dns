Guía de Configuración

  1. Ajustes → Conexiones / Redes e Internet → Más ajustes
  2. DNS privado → Nombre de host
  3. Escribir: dns.xdp.es y guardar
  1. Descargar el perfil .mobileconfig (DoH) en Safari.
  2. Ajustes → Perfil descargado
  3. Pulsar Instalar y confirmar.
  1. Configuración → Red e Internet → Wi-Fi / Ethernet
  2. Asignación de DNS → Manual (IPv4: 85.208.114.51)
  3. Cifrado DNS → Solo cifrado (DoH) con plantilla: https://dns.xdp.es/dns-query

En /etc/systemd/resolved.conf:

[Resolve]
DNS=85.208.114.51#dns.xdp.es 2a0e:97c0:c40::51#dns.xdp.es
DNSOverTLS=yes
DNSSEC=allow-downgrade

Reiniciar servicio: systemctl restart systemd-resolved

Firefox: Ajustes → Privacidad y Seguridad → DNS sobre HTTPS → Personalizado: https://dns.xdp.es/dns-query

Chrome / Brave / Edge: Configuración → Privacidad → Usar DNS seguro → Personalizado: https://dns.xdp.es/dns-query
